# FOR THE CULTURE — Editorial Layout Refinement

This revision keeps the working editorial radar and makes the front-end editorial presentation intentionally less repetitive.

## Layout changes
- Reduced the section navigation to HOME / STORIES / MUSIC / CULTURE.
- Removed the editorial RADIO, VIDEO, EVENTS, ARTISTS and COMMUNITY tabs from the FOR THE CULTURE sub-navigation.
- Removed the duplicated radio story/promo panels from the editorial homepage.
- LATEST STORIES now owns the newest four stories.
- NEW MUSIC only uses music stories that are not already visible in LATEST STORIES.
- CULTURE DESK only uses a distinct story not already used above.
- Added a compact THE IDEA panel so the right column can carry brand/editorial meaning without duplicating a story.
- Added MORE FROM THE CULTURE only when genuinely additional stories exist.
- If there is not enough distinct content, the extra section stays hidden rather than filling space with repeats.

## Editorial sources
The radar now includes:
- The NATIVE

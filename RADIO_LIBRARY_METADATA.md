Galaxy Fire Studios • DJ NEBULAE

## Library
37 authorized radio tracks are included:

The Beat Store library remains separate. No files from `public/beats/` were added to the radio rotation.

## Rotation
The browser radio now uses a smart-random selection system:
- No immediate repeat of the same track.
- Prefers tracks that have not played during the current library pass.
- Avoids the same artist back-to-back when there are viable alternatives.
- Resets the play-through after the library has been exhausted.
- Keeps Recently Played tied to actual playback.
- Existing pause/resume, autoplay attempt, natural track advance and navigation persistence were preserved.

## Metadata
Metadata was built from the audio file's embedded tags/filenames and checked against public music references where reliable matches were available. Uncertain fields are intentionally left blank rather than invented.
